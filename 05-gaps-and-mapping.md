# Разрывы, карта DMBOK, профстандарт, глоссарий

## Наблюдаемые разрывы

1. Формальный владелец контейнеров не назначен; слой вне контура владения
   функции данных — Governance 3, роли 16. См. 04-metadata-lineage.md.
2. Связь план-факт по названию вместо кода — Modeling 5, RDM 10.
   Связь по названию реализована в DAX-мерах отчёта — зона BI-аналитика.
   Категории плана задаются брифом и инструментом аналитика. Разрыв расположен
   на шве двух зон владения: сопоставлением целиком не владеет ни одна сторона,
   и контроль этого шва не закреплён.
3. Переименование источника без уведомления и мониторинга — DQ 13, Governance 3.
4. Маппинг составных правил не вынесен в справочник — RDM 10, Metadata 12.
5. Версии бизнес-правил не формализованы — Governance 3, Metadata 12.
6. Lineage и история миграции не были документированы — Metadata 12.
7. Обнаружение ошибок реактивно, через жалобу — DQ 13.

Формулировки нейтральные: это наблюдения о процессе, не оценка работодателя.

## Глоссарий

| Термин | Определение |
|---|---|
| SPV | супервайзер полевой команды, носитель норматива |
| SFA | мобильная система сбора факта активностей |
| DWH | хранилище данных, ClickHouse |
| Контейнер | интеграционная таблица PostgreSQL; слой историчности оргструктуры и версий плана |
| План исходный | столбец 1, план как загружен на текущий месяц |
| План скорректированный | столбец 2, план после корректировки; исходный сохраняется |
| Категория плана | составное правило брифа над кодами SFA |
| Маппинг по названию | связь категории плана и факта SFA по тексту, не по коду; реализована в DAX-мерах отчёта |
| CDE | критичный элемент данных, ошибка в котором меняет оценку человека |
| Operational DQ | контроль качества на стороне расчёта |
| Strategic DQ | устранение корневой причины на источнике |
| Lineage | прослеживаемость: откуда пришло значение |
| Bus factor | риск знания, сосредоточенного в одном человеке |
| Steward de facto | функции управления данными без формального мандата |
| Shadow IT | решение, скрытое от IT и не каталогизированное; к данному слою не применимо |
| Governance debt | легитимный по использованию слой без владельца и stewardship в целевой модели |
